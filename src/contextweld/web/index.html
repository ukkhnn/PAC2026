분석과 확인 이력

이 데모에서 확인할 것

완성된 흐름을 따라가며 어디에 맥락이 도움이 되고, 언제 확인이 필요한지 살펴보세요.

  1. 정상 표기

    사진과 계획이 일치하면 시연 프로그램 후보가 나옵니다.

  2. 모호한 수기

    준비된 6 / 8 후보에 계획 치수 6을 연결하면 후보가 좁혀집니다. 원본 확인은 계속 필요합니다.

  3. 작업계획 충돌

    사진의 8을 계획의 6으로 덮어쓰지 않고 보류합니다. 시연에서 원본을 다시 확인했다고 가정한 경우에만 치수 수정과 이유를 기록하세요.

  4. 확인 이력 재사용

    모호한 수기에서 결과를 확인한 뒤 이력 사례를 분석하세요. 같은 작업의 확인 기록을 참조합니다. 계획 버전을 바꾸면 재사용하지 않습니다.

  5. 다른 부재의 계획

    사진과 계획의 부재가 다르면 후보를 확정하지 않습니다.

실제로 동작하는 부분

규칙 대조, 근거 조회, 작업자 확인·수정·보류, SQLite 이력 저장, 기록 내보내기. macOS에서는 업로드한 PNG/JPEG 사진에 Apple Vision OCR을 실행합니다.

아직 검증하지 않은 부분

실제 조선소 표기·수기 인식 성능, 현장 WPS 적합성, 임베딩 검색, VLM 의미 추론, 로봇 제어. 예제 이미지는 합성 자료이며 인식 후보가 준비되어 있습니다.
