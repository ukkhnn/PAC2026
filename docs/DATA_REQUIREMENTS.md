# 데이터 요구사항과 현장 검증

표기 인식에서 용접조건 후보까지의 판단을 검증하려면 이미지와 의미·작업 맥락·기준을 연결한 자료가 필요하다. 현재 실제 현장 데이터와 적용 기준은 확보되지 않았다.

## 필요한 자료

| 자료 | 필요한 항목 | 활용 |
|---|---|---|
| 원본 이미지 | 정형·수기 표기, 촬영 조건, 훼손·오염 사례 | 검출·인식과 오류 분석 |
| 표기 정답 | 영역, 문자, 약어·기호의 의미, 관련 표기 | 문자·의미 정확도 평가 |
| 부재·작업 정보 | 식별자, 위치, 재질·두께·자세 등 해당 판단에 필요한 정보 | 맥락 연결과 기준 적용 |
| 표기 규칙 | 약어 사전, 현장 규칙, 적용 대상·버전 | 해석 근거 |
| 용접 기준 | WPS 또는 조건표, 적용 범위·버전 | 작업·조건 후보 선택 |
| 작업계획·이력 | 예정·완료·수정·취소 상태, 시각, 대상 작업 | 맥락 타당성 검토 |
| 최종 판단 | 선택한 작업·조건, 작업자 확인과 근거 | 추천과 확인 절차 검증 |

모든 자료에 출처, 사용 가능 범위, 실제·합성·시연용 구분을 기록한다. 데이터 배치는 [data/README.md](../data/README.md)를 따른다.

## 현장 확인 항목

- 기대 출력이 작업·WPS 후보인지, 구체적인 설정값까지인지.
- 빈번하거나 영향이 큰 표기 오해와 작업자 확인 대상 사례.
- 작업계획·선행작업·수정 이력을 입력으로 확보할 수 있는지.
- 작업 위치·방향·순서의 표현 방식과 좌표 기준.
- 표기 규칙과 용접 기준이 적용되는 공정·재질·장비·문서 버전.
- 원본 자료를 외부 모델로 처리하거나 공개 데모에서 사용할 수 있는 범위.

## 자료가 없는 경우

개발에는 명시적으로 표시한 시연용 자료와 기준을 사용한다. 이 결과는 기능 연결과 판단 절차를 검증하는 데 사용하며 실제 현장 성능으로 표현하지 않는다. 현장 자료 확보 후 독립된 평가 사례로 재검증한다.

## 검증 기록

현장 확인 결과에는 확인일, 질문, 답변 요지, 관련 자료·버전, 영향 받는 요구사항, 남은 불확실성을 남긴다. 공개 저장소에는 공개 가능한 내용만 포함한다.
