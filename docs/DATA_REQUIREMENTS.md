# 데이터 요구사항과 현장 검증

기준일: 2026-10-10. 표기 인식에서 용접조건 후보까지의 판단을 검증하려면 이미지와 의미·작업 맥락·기준을 연결한 자료가 필요하다. 공개 철골 이미지의 개발 표본은 확보돼 있지만 대상 기업의 현장 데이터·승인 기준과 최종 문서 코퍼스는 미확보다. 확보 사실은 [참고 자료](SOURCES.md), 현재 범위는 [데모 스펙](DEMO_SPEC.md), 원문 수집·추출·검수·적재 절차는 [문서 적용 계획](DOCUMENT_APPLICATION_PLAN.md)을 따른다.

## 필요한 자료

| 자료 | 필요한 항목 | 활용 |
|---|---|---|
| 원본 이미지 | 정형·수기 표기, 촬영 조건, 훼손·오염 사례 | 검출·인식과 오류 분석 |
| 표기·관계의 기대 결과 | 문자, 약어·기호의 의미, 화살표 대상, 판독/보류 가능 여부 | 시나리오·소량 입력의 실제 출력과 비교해 기능 확인 |
| 부재·작업 정보 | 식별자, 위치, 재질·두께·자세 등 해당 판단에 필요한 정보 | 맥락 연결과 기준 적용 |
| 표기 규칙 | 약어 사전, 현장 규칙, 적용 대상·버전 | 해석 근거 |
| 용접 기준 | WPS 또는 조건표, 적용 범위·버전 | 작업·조건 후보 선택 |
| 작업지시·개정 | 프로젝트·부재·이음, 문서 ID·개정, 유효 시점, 보류·취소 등 상태 | 유사도 검색과 분리한 정확 조회 |
| 사용자 수정 | 수정 전후, 대상 실행·관측·필드, 이유·시각·주체 | 원본 보존·감사 및 명시적 별도 재검토. 일반 RAG·학습 데이터에서 제외 |
| 제조사 출력 프로파일 | 필드·단위·필수값·변환 규칙·조건 ID 종류와 출처 | [입력 명세](WELDING_ROBOT_INPUT_SPEC.md)에 근거한 모의 전달·검증 |
| 최종 판단 정답 | 기대 대상·조건·문서 근거·전달값, 보류 여부 | 검증 전용. 추론 입력·RAG 코퍼스에 적재하지 않음 |
| 실행 기록 | 관측 이미지·카메라 자세·단계 순서·실제 모델 출력·검색 근거·모의 수신 응답 | 서버 실행을 로컬 읽기 전용 화면에서 재생 |

모든 자료에 출처, 사용 가능 범위, 실제·합성·시연용 구분을 기록한다. 데이터 배치는 [data/README.md](../data/README.md)를 따른다.

## 피칭 데모에 필요한 자료 묶음

| 묶음 | 최소 구성 | 완료 증거 |
|---|---|---|
| 시뮬레이션 시나리오 | 선명한 마킹 텍스처, 같은 장면의 자세 A/B, 고정 조명·재질·노출 설정, 문서·대상·기대 출력 | 실제 RGB와 촬영 설정을 저장하고 A/B를 별도 관측으로 연결. 반사가 이미 날아간 원본을 텍스처에 고정하지 않음 |
| 소량 기능 확인 | 시나리오 A/B와 필요시 추가 문자·관계·문서 누락 입력 | 실제 출력·근거와 오류·보류 기록. 별도 시뮬레이션·독립 평가셋을 필수로 만들지 않음 |

문서 묶음은 지원 기호의 해설 원문, 값이 기입된 공개 WPS, 같은 대상 ID로 연결한 모사 도면·작업지시, 선택한 모의 제조사 프로파일을 포함한다. 문서 ID·개정·해시·적용 범위·원문 페이지/표/행을 보존하고 추출값을 검수한 뒤 사용한다. 정확 조회, 제한된 문서 검색, 검수한 WPS 구조화 표, 코드 검증을 구분한다. 문서 요약만으로 원문·표 검수가 완료됐다고 표시하지 않는다.

자료 수·초기 모델·검색 조합은 피칭 시나리오가 실제로 연결되는 범위에서 정한다. 정확도 최적화·엄밀한 OCR 비교·독립 평가·정량 합격선은 후속 선택이며 이번 완료 조건이 아니다. 두 사진으로 데모 구성을 정할 수는 있지만 이를 일반적인 인식 신뢰도나 현장 성능의 증거로 주장하지 않는다. 기존 개발 표본과 실험 정답은 변경하지 않는다.

## 현장 확인 항목

- 기대 출력이 작업·WPS 후보인지, 구체적인 설정값까지인지.
- 빈번하거나 영향이 큰 표기 오해와 작업자 확인 대상 사례.
- 현재 작업지시·개정과 필요한 부재 속성을 입력으로 확보할 수 있는지. 과거 수정 이력의 자동 참조는 현재 구현 범위가 아니다.
- 작업 위치·방향·순서의 표현 방식과 좌표 기준.
- 표기 규칙과 용접 기준이 적용되는 공정·재질·장비·문서 버전.
- 원본 자료를 외부 모델로 처리하거나 공개 데모에서 사용할 수 있는 범위.

## 자료가 없는 경우

기업 자료가 없으면 가상 작업지시와 모사 도면임을 명시하고 실제 확보한 공개 문서의 원문 근거에 연결한다. 가상 문서를 실제 기업 승인 문서로 표시하지 않는다. 적용 가능한 근거가 없으면 수치를 채워 넣지 않고 보류한다. 이 결과는 기능 연결과 판단 절차를 검증하는 데 사용하며 실제 현장 성능으로 표현하지 않는다. 향후 현장 성능을 주장하려면 현장 자료와 별도 평가 사례로 검증한다.

## 검증 기록

현장 확인 결과에는 확인일, 질문, 답변 요지, 관련 자료·버전, 영향 받는 요구사항, 남은 불확실성을 남긴다. 공개 저장소에는 공개 가능한 내용만 포함한다.
