# ContextWeld 프로젝트 개요

ContextWeld는 PAC 2026 분과 02의 HD현대로보틱스 미션 03을 위한 용접표기 해석 및 조건 추천 프로젝트다. 이 문서는 문제 정의와 구현·평가 범위를 설명한다. 기준일은 2026-10-02다.

## 미션

미션 03은 선박 블록과 부재에 표시된 정형 마킹과 비정형 수기 문자·숫자·기호·약어를 인식하고, 의미와 작업지시를 해석해 용접 작업과 조건에 연결하는 것을 요구한다.

대회 분과는 기업 문제 해결형 IR 피칭이다. 프로토타입과 함께 문제 적합성, 판단 근거, 검증 결과, 후속 실증 계획을 제시하는 것을 목표로 한다. 공식 요구사항은 [미션 정의서](references/mission-03.pdf), 제출 아이디어는 [기획서](references/idea-proposal.pdf)를 참조한다.

## 제안 방식

시각 인식으로 표기 후보를 생성하고 현재 부재·작업 위치·선행작업·관련 부위 이력·작업계획을 맥락으로 활용한다. RAG는 표기 규칙과 용접 기준 등 관련 문서를 검색해 판단 근거를 제공한다. 불확실하거나 충돌하는 결과는 작업자에게 확인을 요청한다. 승인·수정 기록은 Work Memory에 저장해 관련 후속 작업에서 참조한다.

[추론] 검증할 가설은 작업 맥락이 표기 의미 해석에 도움이 된다는 것이다. 현재 성능은 미측정이며, 잘못되거나 오래된 맥락이 오판을 강화하는 경우도 평가한다.

## 기능 범위

| 미션 요구 | 프로토타입 목표 |
|---|---|
| 표기 검출 | 복수 영역 표시, 문자와 비문자 혼동 사례 확인 |
| 정형·수기 인식 | 인식 후보와 불확실성 표시, 회전·저조도·부분 훼손 사례 평가 |
| 의미·작업지시 해석 | 부재·위치·방향·작업 종류 구조화, 표기 간 관계와 규칙 근거 연결 |
| 작업·조건 판단 | 입력 기준에 따른 후보, 작업 위치·방향·순서 표현, 누락·충돌 시 확인 요청 |
| 시각화 | 원본 영역·해석·근거·조건·확인 필요 항목 표시 |
| 추적과 연계 | 이미지부터 확인 이력까지 연결된 데이터 내보내기 |

초기 구현은 제한된 작업 장면과 표기 유형에서 전체 흐름을 완성한다. 정확한 대상 장면과 데이터 형식은 첫 마일스톤에서 확정한다. 실제 로봇 제어, 별도 모델 학습, 공장 시스템 실시간 연동은 후속 범위로 둔다.

## 판단 원칙

- 이미지에서 읽은 내용, 맥락으로 추정한 내용, 기준 문서의 근거, 작업자 확인 결과를 구분한다.
- 용접조건은 적용 가능한 기준에 연결한다. 근거가 없으면 수치를 생성해 확정하지 않는다.
- 모델 점수를 검증된 정답 확률로 표현하지 않는다.
- 작업계획의 예정 상태와 이력의 완료·수정·취소 상태를 구분한다.
- 한 작업의 수정 결과를 전체 작업의 공통 규칙으로 자동 확대하지 않는다.
- 시연용 자료·규칙·모의 출력을 실제 현장 자료·모델 출력과 구분한다.
- 화면상의 작업 위치 표현과 로봇 좌표·경로 생성은 별도 기능으로 취급한다.

## 시연 사례

| 사례 | 확인할 동작 |
|---|---|
| 정상 | 표기·맥락·기준이 일치할 때 조건 후보 제시 |
| 모호 | 복수 후보를 맥락과 대조하고 후보를 좁힌 근거 표시 |
| 충돌 | 사진·계획·기준의 불일치를 표시하고 확정 보류 |
| 수정 후 후속 작업 | 작업자 확인 이력을 관련 작업에서 출처와 함께 참조 |
| 잘못된 맥락 | 오래되거나 다른 작업의 맥락으로 임의 확정하지 않는지 확인 |

## 평가 계획

문자 인식 정확도, 의미 항목 정확도, 잘못된 조건 추천, 확인 요청 비율, 처리 가능 비율, 처리시간을 측정한다. 맥락 적용 전후를 동일 사례로 비교한다. 항상 보류해서 오류만 줄인 결과를 성능 향상으로 해석하지 않는다.

개발·시연 사례와 평가 사례는 원본 단위로 분리한다. 정답은 출처와 검토 근거를 남기며, 평가 대상의 정답이 작업 이력에 미리 포함되지 않도록 한다. 결과에는 사례 수와 실패 유형을 함께 제시한다. 자체 제작·합성 자료의 결과를 실제 현장 성능으로 일반화하지 않는다.

## 후속 실증

사용자와 도입 주체, 기존 확인 절차에 연결할 위치, 필요한 현장 데이터, 실증의 성공 기준을 구체화한다. 시간·비용 절감 효과는 측정값과 가정을 구분한다. 현재 도입 대상과 효과 수치는 확정되지 않았다.
