# 두산·HD현대로보틱스 용접 입력 명세 안내

정합 갱신일: **2026-10-10 KST**. 기존 2026-10-09 요약의 중복 표와 잘못된 고정 범위를 제거하고, 이 파일은 이전 링크를 위한 안내 문서로 유지한다.

**제조사 입력 항목·자료형·단위·기본값·범위의 기준은 [현대와 두산 용접로봇 입력 파라미터 상세 명세](WELDING_ROBOT_INPUT_SPEC.md)다.** 상세 명세의 공식 출처와 확인일을 함께 사용한다. 이 안내 문서에 수치 표를 복제하지 않는다.

| 확인할 내용 | 기준 문서의 위치 |
|---|---|
| 조사한 제어기·문서 버전과 적용 한계 | 상세 명세 1절 |
| 현대·두산의 주요 입력 비교 | 상세 명세 2절 |
| 현대 아크·위빙·시퀀스·경로·설정 입력 | 상세 명세 3절 |
| 두산 DRL 아날로그·디지털·EIP·모션·감시 입력 | 상세 명세 4절 |
| 마킹 해석과 제조사 조건 연결, 최소 전달 계약, 단위 변환 | 상세 명세 5절 |
| 원문 충돌과 실기 적용 전 확인할 항목 | 상세 명세 6절 |
| 제조사 공식 링크·조회일·원문 식별자 | 상세 명세 7절 |

## 현재 데모에서의 사용 범위

- [데모 스펙](DEMO_SPEC.md)의 **파라미터 생성·모의 수신** 범위에 적용한다. 실제 용접 제어·시공 가능한 프로그램 생성은 완료 요구가 아니다.
- 제조사 명령의 기본값과 입력 범위를 승인된 WPS 조건으로 사용하지 않는다. 작업 문서와 모의 설비 프로파일을 별도로 정하고, [문서 적용 계획](DOCUMENT_APPLICATION_PLAN.md)에 따라 값과 근거를 연결한다.
- `arccond cur/vol`은 연결 용접기 설정에 따라 의미·범위가 달라진다. 이전 요약의 고정 전류·전압 범위는 폐기했다. 상세 명세 3.3절·6절을 따른다.
- 전류·송급·파워, 절대전압·보정값, 로봇 프로그램·제어기 조건·용접기 Job은 각각 구분한다. 정확한 필드와 단위 변환은 상세 명세에서 관리한다.
- 설치 제어기·용접기·통신맵·등록조건과 실제 실행 지원 여부는 아직 검증하지 않았다. 모의 수신 응답을 실제 용접 성공으로 표시하지 않는다.

[오픈 모델·공개 자료 조사 기록](PIPELINE_OPEN_RESOURCES_AND_SCENARIO.md)은 자료 탐색 배경으로만 참고한다. 현재 인식 구성은 [OCR 구성](OCR_PIPELINE_SPEC.md), 문서 적재·RAG 구성은 [문서 적용 계획](DOCUMENT_APPLICATION_PLAN.md)을 따른다.
