# ContextWeld 마일스톤

PAC 2026 본행사를 준비하기 위한 개발 로드맵이다. 2026-10-05 첫 통합 데모, 2026-10-08 제출 패키지 완성을 목표로 한다. 날짜는 계획이며 구현 완료를 의미하지 않는다. 기준일은 2026-10-02다.

## 현재 상태

프로젝트 설명과 디렉토리 구조를 준비했다. 제품 코드, 평가 데이터, 성능 결과, 발표자료는 아직 없다. 다음 단계는 M0의 대상 장면·입출력·자료·기술 구성 확정이다.

## 단계별 목표

| 단계 | 목표일 | 작업 범위 | 완료 기준 | 상태 |
|---|---|---|---|---|
| M0 범위·설계 | 10/2~3 | 대상 장면, 미션 대응표, 입력·출력, 시연 사례, 자료 확보·기술 구성 | 구현 범위와 시연용 가정을 구분한 명세 | 미착수 |
| M1 전체 흐름 | 10/3 | 사진 입력, 결과 화면, 맥락 입력, 승인·수정·보류, 이력 저장 | 시연용 데이터로 전체 흐름 실행, 모의 결과 표시 | 미착수 |
| M2 이미지 인식 | 10/4 | 영역·문자 후보 추출, 의미 구조화, 누락·실패 처리 | 실제 모델 출력과 원본 이미지 영역 연결 | 미착수 |
| M3 핵심 통합 | 10/5 | 맥락 대조, 규칙 검색, 조건 후보, 확인 이력 참조 | 정상·모호·충돌 사례 완주, 근거 부족 시 보류 | 미착수 |
| M4 현장 가정 검증 | 10/6 | 사전 멘토링, 도메인 가정 수정, 범위 고정 | 실제 기준과 시연용 가정 구분, 필수·제외 기능 확정 | 미착수 |
| M5 비교 평가 | 10/7 | 맥락 전후 비교, 잘못된 맥락·훼손·기준 누락 평가, 오류 수정 | 고정 평가 사례 결과표와 실패 분석 | 미착수 |
| M6 제출 패키지 | 10/8 | 실행 안정화, 녹화, 실행 안내, 발표자료·예상 질문 | 재현 가능한 데모, 발표자료, 백업 영상 | 미착수 |
| M7 현장 대응 | 10/9~10 | 현장 요구 반영, 최종 점검, 제출·발표 | 제출본 고정과 공식 마감 준수 | 미착수 |

M1은 M0의 최소 입력·출력 정의 이후 시작한다. M2와 M3는 M1의 구조에 연결한다. 평가 설계와 사례 준비는 초기부터 진행하며, 발표 초안은 통합 데모 이후 작성하고 실제 평가 결과로 갱신한다.

## 검증 기준

- M0: 대상 장면, 자료 출처, 예상 출력, 구현 범위가 서로 일치한다.
- M1~2: 직접 입력해 화면과 인식 결과를 확인할 수 있다.
- M3: 불확실한 결과를 임의로 확정하지 않고 근거·확인 이력을 추적할 수 있다.
- M4: 현장 검증을 거친 항목과 미확인 가정이 구분된다.
- M5: 측정값·실패 사례·표본 수가 남아 있고 결과를 재현할 수 있다.
- M6: 실행 안내를 따라 시연할 수 있으며 네트워크·API 장애 시 사용할 녹화본이 있다.

## 일정 변경 기준

| 상황 | 대응 |
|---|---|
| 10/5 통합 데모 미완성 | 표기 종류·화면 기능을 줄이고 전체 흐름에 집중 |
| 10/6 기업 자료 미확보 | 시연용 기준을 명시하고 현장 검증 계획을 제시 |
| 10/7 개선 미확인 | 향상을 주장하지 않고 실제 결과와 실패 원인 제시 |
| 10/8 이후 | 새 기능 추가를 종료하고 오류·발표·백업에 집중 |

작업자 확인과 추적성은 범위 축소 시에도 유지한다.
