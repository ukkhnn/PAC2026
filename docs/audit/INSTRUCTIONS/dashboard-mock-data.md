# 지시서 — 관리자 대시보드 목업 정정

대상: 진단 F 항목. 이 지시서의 모든 항목은 `(claude 제안사항)`이며 실행 여부는 별도 판단 대상이다.

## 배경

관리자 대시보드 preview의 run 데이터 중 `run_kind`이 `presentation_scenario`인 항목은 화면을 먼저 보여주기 위해 `run_outcome` 등이 미리 채워진 시나리오 값이다. 실제 종단 실행(`run_kind: weld_pipeline`)은 상태를 동적으로 기록한다.

## 작업 (claude 제안사항)

1. **목업과 실제 실행을 분리 표시** — 대시보드에 적재된 run이 `presentation_scenario`(목업)인지 실제 실행 기록인지 사용자가 구분할 수 있게 한다. 목업 항목에는 "모델 원문·추론 시간·ACK 없음"을 드러낸다.
2. **`run_outcome` 출처 명시** — 목업 run의 `run_outcome`이 실제 실행에서 나온 값이 아니라 시나리오 정의값임을 메타데이터에 남긴다.
3. **실제 실행 기록과 교차 연결** — 동일 부재·이음의 실제 실행(`shipyard-connected-01`)이 있으면, 목업 화면에서 해당 실행 기록으로 링크해 실제 전달·ACK 원문을 확인하게 한다.

## 완료 기준 (claude 제안사항)

- 대시보드 화면에서 목업과 실제 실행이 혼동되지 않고, 목업임이 명시된다.
- 목업 run이 "실제 반사 감지·재촬영 성공"으로 보이지 않는다.
