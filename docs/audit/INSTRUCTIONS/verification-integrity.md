# 지시서 — 번들 검증 무결성 보강

대상: 진단 G 항목. 이 지시서의 모든 항목은 `(claude 제안사항)`이며 실행 여부는 별도 판단 대상이다.

## 배경

- `weld_pipeline.verify_pipeline()`은 `checksums.json`에 나열된 파일만 재해시한다. 번들에 새 파일을 추가해도 검증이 통과한다(추가 파일 미탐지).
- 한쪽 제조사 수신이 거절되는 부분 전달 시 전체 `run_outcome`·전달 상태 표기가 실제와 일치하는지 별도 확인이 필요하다.

## 작업 (claude 제안사항)

1. **추가 파일 탐지** — `verify_pipeline()`이 `checksums.json`에 없는 파일을 감지하도록 보강한다. 번들 루트 전체를 순회해 체크섬 목록에 없는 파일이 있으면 검증 실패로 처리한다.
2. **부분 전달 상태 표기 검토** — 두 제조사 중 한쪽 수신이 거절된 경우, `manifest`의 `run_outcome`·`delivery_status`·`manufacturers`가 실제 수신 상태와 일치하는지 확인하고, 부분 성공을 정확히 나타내는 값으로 정리한다.
3. **검증 테스트 추가** — 추가 파일 주입·변조를 재현하는 테스트를 추가해 회귀를 막는다.

## 완료 기준 (claude 제안사항)

- 번들에 파일을 추가하거나 변조하면 `verify_pipeline()`이 이를 감지한다.
- 부분 전달 시 전체 상태가 실제와 일치하게 기록된다.
