# E1-003 — 대안 OCR 구성 비교

2026-10-09, 최초 인식 실행 전에 고정.

- 표본·정답·영역 대응·정규화·채점은 E1-001 그대로다. 같은 10장·채점 표기 28개를 전체 이미지 및 정답 영역 crop으로 처리한다.
- 비교 대상은 E1-001 Vision과 RapidOCR 3.10.0 + ONNX Runtime 1.30.0 CPU 기본 PP-OCRv6 small 구성이다. 공개 패키지를 실험 전용 가상환경에 고정 설치한다.
- RapidOCR 기본 검출·인식·180도 방향 분류, 내부 크기 조절·회전 crop을 그대로 사용한다. 따라서 순수 모델만의 차이가 아니라 두 인식 시스템 구성의 비교다. 외부 네 방향 회전은 적용하지 않는다.
- CPU thread는 4로 제한한다. 텍스트 score 임계값은 기본 0.5다. 임계값을 결과에 맞춰 바꾸지 않는다. 원본 다각형·문자·confidence를 보존하고 채점에는 외접 사각형을 쓴다.
- 기본 다국어 인식기를 사용하며 언어·문자 사전을 평가 라벨에 맞춰 제한하지 않는다. 제품 부재 목록·문자 정답·작업지시를 모델에 제공하지 않는다.
- API가 단일 문자열을 반환하면 top3 결과라고 과장하지 않는다. 문자 단위 confidence는 정답 확률이 아니다.
- 첫 호출은 모델 초기화가 포함될 수 있다. 총 시간·표본 수·환경을 기록하되 Vision과 다른 내부 처리·환경의 속도 차이를 모델만의 효과로 해석하지 않는다.
- 실제 사용된 ONNX 가중치 파일·설정·패키지 목록의 해시와 원문 출력을 보존한다. 원본 사진의 추가 다운로드나 테스트 분할 접근은 하지 않는다.
- 채점 개선이 나와도 개발 표본 결과이며 현장 성능을 주장하지 않는다. 실패와 기존 기준선 대비 악화 사례를 함께 기록한다.
