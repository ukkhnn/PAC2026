# E4-001 — 실제 OCR 후보와 가상 작업지시 연결

2026-10-09, 연결 실행 전에 고정.

- 목적: 실제 OCR 관측을 기존 연결 로직에 넣고 오독·불확실성·취소·잘못된 맥락이 어떻게 남는지 검증한다. 검색기 우열이나 실제 생산시스템 효과를 측정하지 않는다.
- 입력: E1-003 RapidOCR의 전체 이미지 관측 전부. 문자 정답으로 관측을 미리 골라내지 않는다. crop이나 회전 정답 선택은 사용하지 않는다.
- 가상 작업자료: 배포자 라벨에서 부재번호를 가져와 이미지마다 별도 블록의 가상 지시를 작성한다. 사진과 실제로 연결된 기업 지시가 아니다. 이 구성은 연결 경로 시험용이며 독립 정확도 평가가 아니다.
- 원문 문자·모델·이미지 해시·관측 영역을 보존한다. 부재번호로 허용되지 않는 문자열은 이유와 함께 보존하고 matcher 입력에서만 제외한다. 내부 공백·문자 혼동을 교정하지 않는다.
- 일부 후보가 지원되지 않아 제외됐으면 남은 하나가 지시와 맞더라도 관측의 확정으로 바꾸지 않고 adapter 상태를 review_required로 둔다. matcher 원본 결과도 별도로 보존한다.
- 정상 맥락, 존재하지 않는 블록, 최신 개정이 모두 취소된 맥락을 같은 실제 관측에 적용한다. 연결 변화는 fixture 구성의 결과이며 모델 성능이 아니다.
- 지역 정답과 OCR 관측의 IoU 대응은 사후 결과 분석에만 사용한다. 어려움 표시 라벨은 문자 성능 집계에서 제외하며 해당 영역/기타 표기는 unscored로 남긴다.
- 지시 연결 여부와 올바른 부재를 읽었는지는 분리한다. execution_authorized는 항상 false여야 한다.
- 복수 후보·지원되지 않는 후보 보존은 별도의 작성한 제어 입력으로 검증하고 실제 OCR 관찰과 섞어 세지 않는다.
