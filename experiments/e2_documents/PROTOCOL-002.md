# E2-002 — 문서 제공 효과의 로컬 모델 재확인

2026-10-09, E2-001의 전체 출력 검토 후 새 모델 실행 전에 고정.

E2-001의 0.5B 모델은 근거 문서를 제공해도 사실 질문을 자주 보류하고 요구 JSON 형식을 지키지 못했다. 자료와 검색의 문제인지 모델·프롬프트 조합의 한계인지 구분하기 위해 공개 1.5B 모델로 같은 문서 제공 비교를 수행한다.

- corpus.json, questions.json, rubric.json, system prompt, BM25, 조건 순서, 최대 생성 128 tokens, greedy decoding을 그대로 유지한다. 정답 기준을 바꾸지 않는다.
- 모델만 Qwen2.5-1.5B-Instruct 고정 버전 `989aa7980e4cf806f80c7fef2b1adb7bc71aa306`으로 바꾼다. 실행 자원은 Apple MPS float16을 사용한다. 따라서 모델 간 차이에 장치·정밀도 차이도 포함되며 순수 크기 효과로 단정하지 않는다.
- E2-002 안에서는 모든 조건의 모델·장치·정밀도를 동일하게 한다. 주 비교는 여전히 none/full/bm25다.
- E2-001의 출력·환경·프로토콜을 보존한다. 이번 자료·질문을 더 큰 모델의 독립 검증이라고 부르지 않는다.
- 모든 27개 응답을 원문으로 보존하고 동일 rubric으로 개별 검토한다. 어떤 모델도 현장 승인이나 현재 규정 판단에 사용하지 않는다.
