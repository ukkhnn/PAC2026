# E2-001 — 문서 없음 / 작은 자료집 전문 / 검색 제공

2026-10-09, 생성 모델 실행 전에 고정.

## 질문과 범위

작은 자료집에서도 전문 제공보다 검색 제공이 필요한가? 자료에 없는 현장 조건을 모델이 지어내는가?

- 문서는 TWI의 2020년 용접기호 해설에서 작성한 영어 요약 6개, 총 140단어다. 원문 전체나 기업 문서가 아니다. 문서별 원문 절·URL을 corpus.json에 기록한다.
- 공개 해설의 사실 질문 6개와 자료로 답할 수 없는 프로젝트 질문 3개를 사용한다. 영어 모델 능력과 한국어 번역 효과를 혼합하지 않도록 영어로 고정한다.
- 자료·질문·채점 기준은 같은 작업자가 설계한 개발용 예시이며 독립 도메인 평가가 아니다. 최신 규정의 적합성·현장 WPS 승인을 판단하는 실험도 아니다.
- Qwen2.5-0.5B-Instruct 고정 공개 버전 `7ae557604adf67be50417f59c2c2f167def9a775`, 기존 transformers 4.56.1·torch 2.8.0, CPU float32, 4개 스레드, greedy decoding, 최대 생성 128 tokens를 사용한다. 작은 모델은 실행 가능성을 위한 선택이며 제품 모델 추천이 아니다.

## 비교 조건

| 조건 | 제공 문서 | 고정 항목 |
|---|---|---|
| none | 없음 | 모델·질문·system prompt·출력 형식 |
| full | 요약 자료집 6개 모두 | 같음 |
| bm25 | 같은 6개 중 질문 BM25 상위 2개, 점수 0이면 제외 | 같음 |

BM25는 영어 소문자 영숫자 토큰, 고정 불용어, k1=1.5, b=0.75를 사용한다. 동점이면 문서 ID 오름차순이다. 정답·채점 기준은 검색이나 생성 입력에 넣지 않는다. 질문 파일과 rubric 파일을 분리하며 실행기는 rubric을 읽지 않는다. 전문은 이 요약 자료집 전체라는 뜻이며 TWI 원문 전체라는 뜻이 아니다.

system prompt는 제공 근거가 있으면 인용하고, 판정할 수 없으면 UNKNOWN을 쓰며, 현장 수치·승인·작업 상태를 만들어내지 말라고 지시한다. 문서 없음 조건에서도 모델의 일반 지식 답변은 허용하므로 답변 정확도와 인용 근거 여부를 분리한다.

## 측정과 검수

- 답변 정확도: 6개 사실 질문의 필수 개념을 모두 충족하는지 원문·rubric과 대조한다. 반대 주장이나 근거 없는 추가 단정은 실패로 처리한다.
- 보류: 3개 자료 밖 질문에서 수치·승인·작업지시를 지어내지 않고 모른다고 했는지 본다.
- 근거: 답변이 맞고 필요한 source ID를 모두 인용했는지 별도 측정한다. none의 근거 0은 조건 자체에서 예상되는 결과다.
- 검색: 6개 답변 가능 질문에서 필요한 문서가 top2에 포함됐는지 생성 정확도와 별도 측정한다.
- 형식: 유효한 JSON 여부와 요청하지 않은 텍스트·잘린 출력을 기록한다. 형식 실패와 의미 정답을 분리한다.
- 모델의 원문 출력 27개를 보존하고 사람이 검토 가능한 표와 판정 이유를 남긴다. 자동 키워드 점수만으로 성능을 확정하지 않는다.
- 입력 tokens·출력 tokens·추론 시간을 기록한다. 단일 실행이며 조건별 순서의 캐시·초기화 영향으로 속도 우열을 확정하지 않는다.
- 필요하면 실패 원인을 진단하지만 프롬프트·질문·정답·검색 규칙을 결과에 맞춰 바꾸지 않는다. 후속은 새 실험 ID다.
