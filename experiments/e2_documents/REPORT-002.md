# E2-002 — 문서 제공 비교 재확인

2026-10-09 · 실행 완료. [사전 프로토콜](PROTOCOL-002.md), [전체 응답 27개](results-002/outputs.jsonl), [개별 판정](results-002/review.json).

## 결론

1.5B 모델에서 요약 자료집 전문 제공은 사실 질문 5/6, BM25 상위 2개 제공은 4/6을 완전히 답했다. 문서 없음은 0/6이었다. **이 작은 자료집에서는 전문 제공으로 시작할 근거가 있으며, 검색이 더 낫다는 증거는 얻지 못했다.** 차이는 단 한 질문이므로 일반적인 RAG 우열로 확대하지 않는다.

| 지표 | 문서 없음 | 요약 자료집 전문 | BM25 상위 2개 |
|---|---:|---:|---:|
| 사실 질문 완전 정답 | 0/6 | 5/6 | 4/6 |
| 자료 밖 질문 적절한 보류 | 3/3 | 3/3 | 3/3 |
| 정답이며 필요한 출처 ID 제시 | 0/6 | 4/6 | 4/6 |
| 요청 JSON 객체 형식 준수 | 0/9 | 3/9 | 5/9 |
| 필요한 문서 포함 | 해당 없음 | 6/6 | 6/6 |

답변의 의미와 JSON 형식은 별도로 평가했다. Q1·Q3 전문 응답은 내용·근거가 맞아도 코드 fence 때문에 형식 지시를 위반했다. Q6 전문 응답은 `below`라는 위치는 맞지만 배열이며 출처를 제시하지 않았다.

## 비교가 알려준 것

- Q3 검색 제공은 필요한 문서 D4를 받았지만 요구한 세 가지 개념을 구체적으로 답하지 않았다. 검색에서 근거를 찾는 것과 모델이 활용하는 것은 별개의 문제다.
- Q5는 전문·검색 모두 부분 답변이었다. 사전에 고정한 두 개념 중 하나가 빠져 완전 정답으로 세지 않았다. 채점 기준을 출력에 맞춰 완화하지 않았다.
- 자료 밖 현장 수치·승인·현재 지시 질문에는 두 조건 모두 보류했다. 다만 보류 결과도 대부분 요구 JSON 형식은 아니어서 앱 연동에는 별도 검증이 필요하다.
- 문서 없음 Q2에서 제공되지 않은 `ID: 0`을 출처처럼 적었다. 값만 보는 것 외에 인용의 실재성도 확인해야 한다.

E2-001 대비 사실 응답 능력은 좋아졌지만 모델·장치·정밀도도 달라 순수 파라미터 수 효과로 단정하지 않는다. E2-002 안에서는 모델과 장치를 고정하고 문서 제공 방식만 바꿨다.

## 자료와 환경

자료는 TWI의 2020년 해설을 바탕으로 작성한 140단어 요약 6개다. 전문은 이 요약집 전체를 뜻하며 규정 원문 전체가 아니다. 자료와 질문을 함께 설계한 개발용 실험이며 한국어·표·긴 문서·문서 충돌의 효과는 측정하지 않았다. 출처와 상세 문항은 [corpus.json](corpus.json), [questions.json](questions.json), [rubric.json](rubric.json)에 있다.

Qwen2.5-1.5B-Instruct `989aa7980e4cf806f80c7fef2b1adb7bc71aa306`, MPS float16, transformers 4.56.1·torch 2.8.0, greedy decoding을 사용했다. 동일 system prompt·질문·검색 규칙을 유지했다. [모델 해시](model-large-manifest.json), [실행 환경](results-002/environment.json), [집계](results-002/summary.json)를 보존했다. 유료·외부 생성 API는 사용하지 않았다.

## 재현·판정

```sh
python3 experiments/e2_documents/prepare_models.py large
python3 experiments/e2_documents/run_larger.py rerun-large-001
python3 experiments/e2_documents/grade_documents.py results-002
```

두 번째 명령은 Apple MPS를 사용할 수 있는 로컬 실행 환경이 필요하다. 세 번째는 저장된 원문과 질적 판정을 재집계한다. 새 실행은 고정 rubric으로 개별 검토해야 하며 자동으로 의미 정답을 만들어내지 않는다. 판정은 작업 에이전트가 원문과 비교한 것으로 독립 도메인 전문가 검토는 아니다.

## 결정

현재 규모에서는 자료집 전문 제공을 단순한 기준선으로 유지한다. 자료량·표·적용 범위가 늘어나 검색이 필요한 질문이 생길 때 E3를 진행한다. 앱 연결 전에는 출력 형식과 인용 ID가 실제 제공 문서에 존재하는지 검증하고, 부정확한 응답은 원문과 함께 확인 대상으로 남겨야 한다.
