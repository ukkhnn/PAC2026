# E1-002 — 네 방향 OCR과 후보 보존

2026-10-09, 새 OCR 실행 전에 고정.

- 질문: 같은 Vision 인식기에 0/90/180/270도 입력을 제공하면 표기 완전 일치나 후보 내 정답 포함률이 달라지는가?
- 표본: E1-001의 고정 이미지 10장·29개 라벨, difficult 1개 제외한 28개. 기존 라벨·표본·결과를 수정하지 않는다.
- 전체 이미지 및 E1-001과 같은 정답 영역 crop 각각 네 방향을 실행한다. Pillow의 픽셀 손실 없는 90도 단위 전치만 사용한다. crop은 여전히 정답 영역 제공 조건이다.
- Vision 설정·언어·교정·채점·정규화는 E1-001과 같다. 단순 방향 추가와 후보 병합만 바꾼다.
- 각 관측 영역을 원래 좌표계로 역변환한다. 정답 좌표/문자 없이 관측끼리 IoU 0.3 이상이면 병합한다. confidence 내림차순, 동점이면 작은 회전각·앞선 관측 순으로 대표 영역을 선택한다. 이미 대표가 된 영역에만 나머지를 붙이는 탐욕 방식으로 인접 표기를 연쇄 병합하지 않는다.
- 병합 후보는 최대 confidence 내림차순, 동점이면 작은 회전각·앞선 후보 순으로 정렬한다. 대소문자/앞뒤 공백만 정규화하여 중복을 제거하고 원문과 회전·영역·순위를 보존한다. confidence는 확률이 아니라 고정된 비교용 선택 규칙이다.
- 정답을 보고 최선 회전이나 문자열을 선택하지 않는다. 단일 대표 top1, 상위3, 전체 후보 내 정답, 후보 수/모호함을 함께 기록한다.
- 새 실행의 0도와 네 방향 병합을 주 비교로 삼는다. 과거 E1-001과 0도 결과가 달라지면 차이를 기록한다.
- 영역 대응·CER는 기존 코드로 계산한다. full은 자동 영역이며 crop은 위치를 아는 진단 조건이다. 미대응 예측을 모두 오검출로 단정하지 않는다.
- 시간은 초기화 영향이 있는 단일 실행이다. 회전 입력 수와 총 호출 시간을 적으며 회전 네 배를 독립 표본 네 배로 세지 않는다.
- 결과를 본 뒤 선택 규칙을 수정하지 않는다. 필요하면 새 실험 ID로 분리한다.
