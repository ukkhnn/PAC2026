# PV2 통합 메모 — 공통 README·MILESTONES·명세 정정안

병렬 UI 작업과 충돌하지 않도록 공통 문서는 직접 고치지 않았다. 원본 체크아웃의 미커밋 수정(README·MILESTONES·OCR 명세·실험 README)은 그대로 두었다. 반영할 내용만 여기에 제안한다.

1. CTX-001 문구 제거 또는 강등. 대상은 미커밋 README "최신 인식 실험" 단락, MILESTONES "고정 이미지 맥락 실험" 행, OCR 명세 14절, 실험 README 첫 단락이다.
   - 정정안: "CTX-001은 정답이 든 후보 목록에서 고르게 한 설계여서 사용자가 거부했다. 현재 성능·당위성 근거에서 제외한다."
   - 같은 단락의 Isaac `live-03` 갱신 문구는 별개로 유지할 수 있다.
2. 문서 데모 정상 사례 정정. frame-007의 공개 라벨은 `B1Sb30N-15`인데 OCR·VLM 모두 `BISb30N-15`로 읽었다. 모사 작업지시 `BISB30N-15`는 이 오독에서 만들었다. "정상 `received`"는 문서 연결 기능 시연이지 올바른 인식의 증거가 아니라고 명시한다. Isaac 장면 표기도 같은 문자열임을 함께 쓴다.
3. 문서 검색 역할 정정. 인식 단계 검색은 고정 질의 1개로 모든 프레임에 같은 TWI 청크를 넣는다. 인용은 0이고 판정에 쓰이지 않는다. "문서 근거로 해석한다"는 표현을 "일반 참고 근거를 기록한다"로 낮춘다.
4. 실험실 시작점을 `experiments/pipeline_v2/REPORT.md`로 바꾼다. 이번 실행은 축소판 8장이며 나머지 계획은 미실행이라고 적는다.
