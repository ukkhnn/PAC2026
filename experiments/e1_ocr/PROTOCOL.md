# E1-001 — 실제 철골 표기의 전체 이미지 / 정답 영역 OCR

고정일: 2026-10-09. 이 문서는 최초 OCR 실행 전에 정한 조건이다.

## 질문

현재 사용 가능한 Apple Vision으로 공개 철골 사진의 코드를 얼마나 읽는가? 정답 영역을 제공하면 어떤 오류가 남는가?

이는 E1의 초기 진단이다. OCR/VLM 모델 비교나 학습 실험이 아니다. Apple Vision 선택은 설치 없이 실행 가능한 환경을 활용한 것이며 성능 우세를 전제하지 않는다.

## 표본과 자료

- Steel OCR 960px의 `37725284f40deeaccbdeb3734be7b0e90e974305` 버전을 고정한다.
- `train_data/det/train.txt`의 경로를 UTF-8 SHA-256 오름차순으로 정렬해 앞 10개를 선택한다. 문자열 정답·난도·OCR 출력으로 선정하지 않는다.
- 이미지 원본, 원문 라벨과 카드, 다운로드 URL과 SHA-256을 보존한다. 배포자의 정답은 수정하지 않는다.
- `difficult: true` 또는 `###` 라벨은 점수 계산에서 제외하고 개수를 기록한다.
- 최종 테스트 분할은 다운로드하거나 사용하지 않는다. 원본판 테스트 파일 목록과 선정 파일명이 겹치는지 확인한다. 파일명 검사만으로 모든 시각적 유사·파생 중복을 보증하지는 않는다.
- 개발 표본이며 독립 현장 평가가 아니다. 인접 사진·같은 부재의 반복 가능성이 있다.

## 두 조건

| 조건 | 입력 | 정답 정보 사용 |
|---|---|---|
| full | 배포된 960px 이미지 전체 | 인식 단계에서 없음 |
| oracle_crop | 라벨 다각형의 축 정렬 외접 사각형에 각 축 5% 여백, 최소 2px, 이미지 경계로 제한 | 영역 좌표만 사용. 정답 문자는 인식기에 전달하지 않음 |

추가 확대·회전·원근 보정·사전·작업 맥락·문자 교정은 적용하지 않는다. crop은 정답 검출기를 가정한 진단 조건이며 제품 성능이나 자동 영역 검출의 성능으로 해석하지 않는다. 영역 제한은 위치뿐 아니라 배경과 입력 크기도 바꾸므로 변화의 원인을 검출 하나로 단정하지 않는다.

인식 설정은 두 조건 모두 `accurate`, `en-US`, 언어 자동 교정 끔, SDK 기본 request revision과 최소 문자 높이 사용이다. 실제 revision·OS·최소 문자 높이·코드 해시를 실행 결과에 저장한다. 상위 3개 후보와 점수를 보존하되 기본 채점은 1순위다. 신뢰도는 정답 확률이 아니다.

## 대응·채점 규칙

- 다각형은 축 정렬 외접 사각형으로 변환한다. 좌표는 왼쪽 위 원점의 `[x0,y0,x1,y1]` 정규화 값이다.
- OCR 영역과 정답 영역의 IoU가 0.3 이상인 쌍을 IoU 내림차순으로 일대일 탐욕 대응한다. 문자 정답은 대응에 사용하지 않는다. 한 예측을 여러 정답에 중복 사용하지 않는다.
- 같은 규칙을 full과 crop에 적용한다. 분할·합쳐진 OCR 결과를 정답을 보고 재조립하지 않는다. 따라서 영역 단위가 다르면 읽은 문자 일부가 있어도 누락으로 계산될 수 있다.
- 원문 완전 일치와 `strip().upper()` 후 일치를 각각 기록한다. 내부 공백·하이픈·O/0 등은 그대로 둔다.
- CER = 정규화한 정답과 1순위 출력의 Levenshtein 거리 합 / 정답 문자 수 합. 미대응은 빈 출력으로 처리한다. 삽입이 많으면 100%를 넘을 수 있다.
- 영역 대응 수, 정답 일치 수/전체 라벨 수, 상위 3개 내 일치 수, 이미지별 일치 수, 호출 오류 수와 OCR 소요시간을 함께 기록한다.
- 라벨에 없는 다른 문자가 있을 수 있으므로 미대응 예측을 모두 오검출로 단정하거나 precision을 산출하지 않는다. 부가 예측 수는 별도 기록한다.
- 실행 오류는 빈 성공으로 위장하지 않고 오류를 보존한 뒤 실행을 실패 처리한다. 오류가 있으면 해당 실행의 성능 결론을 내리지 않는다.
- 시간은 단일 실행이며 준비·컴파일·다운로드는 제외한다. full 이후 crop 순서로 실행하므로 최초 초기화·캐시 영향을 받는다. 속도 우열의 근거로 사용하지 않는다.

## 완료와 후속 판단

채점 코드의 알려진 정답 사례부터 검증하고 실제 10장에 두 조건을 실행한다. 출력과 원본 일부를 직접 대조해 실패 유형과 라벨의 한계를 남긴다. 다음 모델이나 전처리 선택은 관찰 후 결정하되, 이 실험의 원본 표본·정답·결과는 보존한다. E2~E7이나 제품 OCR 연결 완료로 확대하지 않는다.
