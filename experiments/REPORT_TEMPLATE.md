## 결론

관찰과 결정 한 문장. 미실행이면 결과를 채우지 않는다.

| 항목 | 기록 |

| 자료 | 출처·판본·이용 조건·실제/합성/가상 구분 |
| 표본 | 선택 규칙·분할·독립 원본 수·라벨 수·제외 이유 |
| 실행 환경 | 모델/라이브러리·프롬프트·설정·OS·코드 식별자 |
| 정답 사용 | 평가에만 사용한 것과 입력에 제공한 정보 |
| 측정법 | 분모·누락·오류·정규화·대응 규칙 |

## 사례와 근거

대표 성공과 실패의 ID·정답·실제 출력·원본 위치를 적는다. 결과 전체의 위치도 연결한다.

## 검증·재현

실행 명령, 채점 도구 확인, 실행하지 못한 것, 원본 출력·설정·해시의 위치를 적는다.

## 결정과 다음 질문

유지·교체·보류와 근거를 기록한다. 개발 관찰을 현장 성능으로 확대하지 않는다.
