# E5-001 — 저장된 모델 출력의 구조·인용 검사

2026-10-09. E2-001/002 출력의 형식 실패를 확인한 뒤 검사 실행 전에 고정.

- E2의 실제 54개 응답을 변경 없이 재사용한다. 새 모델 생성·정답 입력·응답 재작성은 하지 않는다.
- JSON 객체, answer 문자열, sources 문자열 배열, 출처 ID가 실제 제공 문서에 있는지를 검사한다.
- UNKNOWN이면 sources가 비어 있어야 한다. 일반 답변은 최소 하나의 제공된 문서를 인용해야 한다. 정확한 출처 ID만 허용한다.
- 형식·출처 오류는 review_required, 올바른 UNKNOWN 객체는 abstained, 구조·출처 검사를 통과한 일반 답변은 candidate로 분류한다. candidate는 사실 검증이나 현장 실행 승인이 아니다.
- 원래 의미 판정은 E2의 고정 rubric·검토를 사용한다. 통과한 사실 정답·틀린/불완전 답변과 보류된 올바른 답변을 분리한다.
- 이것은 E5의 구조·인용 검사 파일럿이다. 재질·두께·WPS 적용성 검사나 사실성 보증을 구현했다고 표현하지 않는다.
