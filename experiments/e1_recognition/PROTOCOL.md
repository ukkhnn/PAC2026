# E1-004 — 정답 영역에서 검출을 생략한 문자 인식 진단

2026-10-09, E1-003의 crop 검출 누락을 관찰한 뒤 별도 실행 전에 고정.

E1-003은 정답 crop을 줘도 내부 검출을 다시 실행해 28개 중 6개만 영역 대응됐다. 위치를 이미 아는 진단에서는 검출기를 생략하면 어떤 문자 인식 결과가 남는지 확인한다.

- 같은 정답 crop 28개, 원본 라벨 그대로 사용한다. 위치를 알고 하는 oracle 실험이며 자동 인식 성능이 아니다.
- RapidOCR 3.10.0 / PP-OCRv6_rec_small, CPU 4 threads. use_det=False, use_cls=False로 검출·방향 분류를 모두 생략한다. 모델의 기본 크기 정규화는 유지한다.
- 원본 방향 0도 및 0/90/180/270도 네 방향을 같은 인식기로 비교한다. top1은 confidence 내림차순, 동점이면 작은 각도로 고른다. 정답 문자열로 고르지 않는다.
- 상위3와 전체 후보 내 정답, 후보 수, 선택 후 완전 일치와 CER를 함께 적는다. 원문·각도·confidence를 모두 남긴다.
- 인식 단독 API의 점수를 원문 그대로 보존하고 임계값으로 버리지 않는다. E1-003의 검출·분류·score 필터와 처리 단계가 다르므로 차이를 검출 효과 하나로 단정하지 않는다.
- E1-001/E1-003의 프로토콜과 성적을 덮어쓰지 않는다. 28개 crop의 112개 방향 입력을 독립 표본으로 세지 않는다.
